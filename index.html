CI/CD Pipeline Lab

This tiny static site exists for one reason: to be built and deployed by a GitHub Actions workflow, so I can watch a CI/CD pipeline run end-to-end.

Not yet deployed.

What the pipeline does

  1. Push to main triggers the workflow.
  2. GitHub Actions checks out the repo and uploads this folder as a Pages artifact.
  3. actions/deploy-pages publishes it via OIDC — no stored deploy secret.
